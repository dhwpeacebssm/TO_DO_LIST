# TO_DO_LIST
## 주제: To_do_list
### 핵심기능
### 1. 사용자 아이디와 비밀번호를 입력받고 회원가입 및 로그인
### 2. 사용자가 원하는 과목과 날짜를 입력받고 캘린더에 보여줌
### 3. today 체크리스트

### 테이블 구성
### 1. users
#### 1. user_id(varchar[50], not null): 사용자의 아이디를 입력받는다. 필수입력
#### 2. password(varchar[225], not null): 사용자의 비밀번호를 입력받는다. 보안을 위해 저장장소를 늘렸다. 필수입력
#### 3. created_at
